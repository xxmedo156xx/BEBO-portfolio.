BEBO Personal Portfolio
========================

Contents:
- index.html
- assets/bebo-photo.jpg

Preview:
Open index.html in a browser.

Deploy:
1. Create a new project on Vercel.
2. Import/upload this folder as a static site (or deploy it with Vercel CLI).
3. Keep the assets folder beside index.html.

Privacy:
The WhatsApp number was intentionally not embedded in this public version.
A public WhatsApp link can expose your phone number to every visitor.
The Telegram button is active.

To add WhatsApp later, add a link inside .contact-actions in index.html:
<a class="contact-link" href="https://wa.me/COUNTRYCODE_NUMBER">WhatsApp ↗</a>
Use your own decision about whether to publish that number.
